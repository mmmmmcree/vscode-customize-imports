# SCM Line Stats · 原生更改悬停

在 Git 原生的 **更改**、**暂存的更改**、文件及文件夹上显示类似源代码管理图表的悬停卡片。卡片包含绿色新增行数、红色删除行数和比例条；默认只在悬停时显示统计；分组名称不包含可见的 `+-` 数字，即使脚本尚未加载也不会短暂出现行内统计。保存只更新统计数据，不主动弹出卡片。首次显示卡片沿用 VS Code 原生悬停的 100 毫秒渐显；卡片刷新时不重复播放，并遵循“减少动态效果”设置。

`0.2.6` 将数字字号、行高和内边距调整为与图表卡片协调的紧凑布局，新增、删除文字与比例条直接使用图表对应的统计色。搭配 `Dark 2026 + One Dark Pro 1.2.14` 并启用 Synthwave 后，两类卡片共用深色渐变底、紫蓝青渐变边框、8px 圆角和柔和光晕，图表分支线与引用标签也使用统一的霓虹配色。其他主题使用各自的图表统计色，缺少该颜色项时回退 Git 装饰色。

`0.2.7` 更新共用注入器，卡片脚本在原生编辑器界面绘制后启动。更新后运行“启用原生悬停”或其他效果插件的更新命令，再按提示重载；行数统计和卡片行为沿用原有实现。

## 安装和启用

1. 从仓库根目录运行 `python scripts/install.py --plugin vscode-scm-line-stats`，或通过“从 VSIX 安装”选择本目录的 `dist/scm-line-stats-0.2.7.vsix`。
2. 运行 **更改统计: 启用原生悬停**，生成并注册彩色卡片脚本，通过共用安全更新器应用。按提示重新加载窗口。
3. 在原生“更改”“暂存的更改”或文件上悬停，查看绿色新增、红色删除和比例条。

需要统一的霓虹卡片外观时，也更新主题并运行 **Dark 2026: 启用或更新 Synthwave 光晕**，再按提示重载。统计脚本与主题样式分别更新，两个命令都需要执行。

若旧版本仍显示行内数字，运行 **更改统计: 启用原生悬停**。该命令会把显示方式切回 `hover` 并修复加载，然后重新加载窗口。

启用命令需要已安装的 **Custom CSS and JS Loader**，把随插件打包的界面脚本加入其加载列表，保留现有自定义脚本。若没有该加载器，命令会打开其安装页面；安装后重新执行启用命令即可。插件启动时只检查脚本版本，安装或更新后请手动执行启用命令；启动检查不改写 VS Code 页面。

`0.2.5` 修复了启动时自动更新与主题启用同时写入工作台页面、导致窗口全黑的冲突。各插件共用跨进程互斥、页面完整性检查和原子替换，更新失败时保留可用页面。统计逻辑、卡片样式和原生 Git 操作继续沿用原有实现。

原生分组尚无公开的悬停扩展接口，因此本插件使用内置 Git 的内部对象接入统计，并通过加载器显示卡片。已在 **VS Code 1.123.0 / Windows** 验证。VS Code 更新后可能需要适配；无法访问原生 Git 分组时会退回独立统计视图。纯文字文件提示属于脚本尚未加载的降级状态；发生错误时会显示错误并记录日志。首次应用和 VS Code 更新后需要重新加载窗口。

卡片、文件提示、命令和设置说明跟随 **VS Code 显示语言**，支持简体中文、繁体中文和英文，其他语言回退英文。英文界面中的启用命令为 **Line Stats: Enable Native Hover**。原生分组和 Git 状态沿用内置 Git 扩展的翻译。

## 统计逻辑

- **更改**：暂存区 → 磁盘工作区，默认包含未跟踪文本文件的新增行数。
- **暂存的更改**：HEAD → 暂存区。
- 部分暂存的文件在两组分别计算，例如“更改”中显示 `+3 −1`，“暂存的更改”中显示 `+2 −1`。
- 保存文件、暂存、取消暂存及 Git 状态变化后自动更新。可运行 **更改统计: 刷新更改行数** 手动刷新。
- 原生图标、暂存按钮、右键菜单、差异编辑器和提交流程继续由 Git 扩展提供。
- 二进制、冲突、子模块和无法读取的文件不计入文本行数；文件提示说明其类型。
- 统计已保存内容，尚未保存的编辑不参与统计。

原生分组、文件卡片支持列表和树视图。树视图的文件夹悬停会递归汇总该目录及子目录中的变更文件，显示文件数、绿色新增、红色删除和比例条。折叠目录同样有效；暂存与未暂存分别计算，父目录包含子目录的数据，分组总计仍按文件计算，避免重复累加。

## 设置

```json
{
  "scmLineStats.presentation": "native",
  "scmLineStats.displayMode": "hover",
  "scmLineStats.includeUntracked": true,
  "scmLineStats.refreshDelay": 400
}
```

`presentation` 可设为 `panel`，使用独立的“更改统计”视图。`displayMode` 可设为 `inline`，持续显示分组总计。切换到独立视图或关闭插件会恢复原生 Git 的分组名称和资源对象。

未跟踪文件以流式读取计算行数，前 8000 字节包含 NUL 时按二进制处理，不应用特殊 Git attributes 文本规则。已跟踪文件采用 Git `--numstat`，禁用外部 diff 和 textconv。单次 Git 命令超时 30 秒，最大输出 32 MiB。失败详情可运行 **更改统计: 查看日志**。

原生卡片面向桌面版 VS Code；独立统计视图也能作为工作区插件在 Remote SSH、WSL 和开发容器中运行。纯浏览器虚拟工作区不支持。
